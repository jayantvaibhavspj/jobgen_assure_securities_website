# Assure Securities — Modern Financial Distribution Web Application

Modernized, high-performance web platform for **Assure Securities**, an AMFI Registered Mutual Fund Distributor (ARN-182137), based in Gomtinagar, Lucknow, India.

## 🌟 Key Features

- **Alternating Contrast Design System**: Distinct alternating light and dark sections across every single page for maximum visual engagement.
- **100% Authentic Assets**:
  - Original banner carousels (`b1-2.jpg`, `b2-1.jpg`, `child.jpg`, `b4-2.jpg`)
  - Authentic illustrations (`img_se.png`, `1_789.png`, `2_fg.png`, `3_what_we_do.png`)
  - Animated live financial intelligence GIFs (`data-analysis.gif`, `analytics.gif`, `report.gif`, etc.)
  - High-definition local thumbnails for all 12 YouTube educational masterclasses
- **Multi-Page React Architecture** via `react-router-dom`:
  - `/` — Homepage with Hero Carousel, Intelligence Bar, About, Products, Calculators, Investor Zone, Videos, Reviews & Contact.
  - `/about-us` — Company story, 15+ years track record, Mission, Vision, and 4 Pillars.
  - `/products` — 7 financial suites (Mutual Funds, FDs, Bonds, Insurance, Tax Saving, PMS/AIF).
  - `/calculators` — 6 interactive calculation engines (SIP, Lumpsum, Child Education, Wedding, Retirement, Vacation).
  - `/investor-zone` — SEBI/KRA KYC verification, Registrar portals (CAMS, KFintech, MF Central) & downloadable forms.
  - `/educational-videos` — 12 video masterclasses with category filters, modal player & research articles.
  - `/become-a-partner` — Sub-broker / associate onboarding with NISM Series V-A support and revenue transparency.
  - `/contact-us` — Lucknow headquarters info, interactive form, and Gomtinagar directions.
  - `/privacy-policy`, `/disclaimer`, `/disclosure`, `/risk-factors`, `/code-of-conduct` — Full statutory compliance disclosures.
- **Interactive Modals**: Instant Consultation booking, Quick SIP calculator teaser, and Partner application modals.
- **AMFI & Regulatory Details**: Fully compliant with ARN-182137 (Validity: July 2027) disclosures and SEBI SCORES redressal links.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/jayantvaibhavspj/jobgen_assure_securities_website.git
cd jobgen_assure_securities_website

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **Routing**: React Router DOM v7
- **Styling**: Vanilla CSS Design Tokens (Variables, Glassmorphism, Micro-animations)
- **Icons**: Lucide React + Custom SVGs
- **Celebration Effects**: canvas-confetti
